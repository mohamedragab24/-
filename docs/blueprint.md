# **App Name**: Fahmani

## Core Features:

- User Registration and Authentication: Allow users to create accounts and log in securely using Firebase Authentication, ensuring email verification.
- Dynamic Home Interface: Display a customized home interface based on user role (Teacher/Expert or Student/Learner).
- Request Feed (Teacher/Expert): Display a feed of new requests matching the teacher's specialization and gender. Includes request title, amount, and meeting time; teachers can accept requests with a button, triggering notifications to the admin and student.
- Request Creation (Student/Learner): Allow students to create new learning requests, categorized for quick selection (study, tech, crafts).
- Request Management: Enable users to manage their requests through categorized tabs (Pending, Accepted, Completed, Canceled).
- Wallet Management: Enable users to manage their funds, view transaction history, add balance (students), and request withdrawals (teachers).
- Profile Settings: Allow users to modify profile details (picture, name, phone, birth date) with restricted email editing. 

## Style Guidelines:

- Primary color: HSL(210, 65%, 50%) - A vibrant blue, representing trust and knowledge.  Hex: #3391FF
- Background color: HSL(210, 20%, 95%) - A light desaturated blue-tinted gray to ensure comfortable readability. Hex: #F0F5FA
- Accent color: HSL(180, 55%, 40%) - A teal color, providing a contrasting but harmonious tone for interactive elements.  Hex: #3BAEAE
- Body and headline font: 'PT Sans' for a modern look with a little warmth or personality.  
- Use consistent, clean icons to represent different categories and actions throughout the app.
- Maintain a clear and intuitive layout, ensuring easy navigation and access to essential features.
- Employ subtle animations for transitions and feedback to enhance the user experience.
