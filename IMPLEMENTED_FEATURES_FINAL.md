تم الحفاظ على أنظمة Firebase/Functions الموجودة وإضافة/تثبيت:
- purchaseCourse + payment completion
- signed video URL protection
- notification campaigns + inbox
- referral code generation
- activity log
- server-side analytics event endpoint
- course search/filter foundation

- accessibility focus/reduced-motion baseline

DRM, CDN/HLS/DASH, Fawry, Vodafone Cash, SMS 2FA, Google/Apple OAuth, production email/Crash analytics.
