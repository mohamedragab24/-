# مشروع منصة وتطبيق فهمني (Fahmt Platform)

تم إعداد وحزم هذا المشروع لحل وتعديل المشاكل التالية:
1. معالجة الشاشة البيضاء (Client-side exception) عند دخول صفحة الكورس.
2. إضافة معاينة الكورس المجانية قبل الشراء وسحب الفيديوهات من Cloudflare R2.
3. تفعيل الدفع الحقيقي وخصم الرصيد من المحفظة أو عبر رقم الهاتف وتحديث المحفظة من لوحة التحكم بشكل فوري.
4. إنشاء صفحة الفاتورة وإتمام الطلب وشعار المنصة وتحويل المستخدم للتطبيق (`fahemny://course-view`).
5. واجهة شاشة المجموعات داخل تطبيق Flutter.
6. واجهة وتفاصيل الإشعارات داخل وخارج التطبيق (In-App / Push Notification).

## هيكل الملفات:
- `web/app/course/[id]/page.tsx` -> صفحة عرض الكورس والمعاينة (Next.js)
- `web/services/paymentService.js` -> خدمات الدفع والمحفظة ومعاملات الفايربيس
- `web/app/order-success/page.tsx` -> صفحة إتمام الطلب والرابط للتطبيق
- `mobile/lib/views/groups_screen.dart` -> واجهة المجموعات (Flutter)
- `mobile/lib/views/notifications_screen.dart` -> واجهة الإشعارات (Flutter)
